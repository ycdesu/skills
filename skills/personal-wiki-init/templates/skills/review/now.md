# Now review

`{{WIKI}}/now.md` is the single-glance focus page. One place that always tells me what I'm working on this quarter, this milestone, this week — so I don't have to re-derive it from syntheses each session.

I maintain `now.md` manually. Don't update it silently — the page is load-bearing and surprise edits erode trust in it. Update only on my explicit request: read syntheses, current milestones, recent log entries, propose updates to all three sections; confirm before writing.

**What `now.md` does NOT contain**:

- Long-form planning — that's `{{WIKI}}/syntheses/`.
- Historical records — that's `{{WIKI}}/log.md`.

**Staleness signal**: if `now.md`'s `updated:` is more than ~3 weeks behind today, surface that during the next session and offer a Now review.
